**DIFFERENT TYPES OF KEYS**


**Super key:**

Super key is a combination of columns as long as it can uniquely identify rows.

**Candidate Key** 

Candidate key is the minimal amount of keys need to uniquely identify a rows. Ex name birthdae

**Primary key**

Primary key is a candidate key that we select and must uniquely identify the row. There can ben one or more candidate keys. Called as composite primary keys. 

**Foreign Keys**

For example, there is a user table and a order table. suppose a order table has a user_id foreignkey it determines the relation between the user and the order. 

Foreignkey can consist of any candidate key. 
It enforces referencial integrity.
